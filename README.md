# Flappy Bird Arcade Clone
This application is a browser based arcade game where players guide a bird through obstacles to score points.

## Description
The game uses an HTML5 canvas element combined with a requestAnimationFrame loop to handle physics updates and rendering. Obstacles are generated dynamically at intervals, tracking player collision boundaries and incrementing score upon successful clearance.

## Capabilities
- Classic arcade cabinet visual styling
- Responsive keyboard and mouse controls
- Persistent high score tracking
- Smooth collision detection engine

## Structure
- `index.html`: Markup for the arcade game container
- `style.css`: Visual styling and cabinet layout
- `script.js`: Game loop physics and controls

## Execution
Open `index.html` in a browser. No install or build step.
